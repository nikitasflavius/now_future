# Now&Future

Личный атлас улиц «как есть» и «как могло бы быть». Сайт на GitHub Pages, данные в Google Таблице, фото в папке «Now&Future — фото» на Google Диске.

Файл `Code.gs` (отдельно от этого архива) вставляется в Apps Script таблицы, в репозиторий его класть не нужно.

Папка `seed` нужна только для переноса двух примеров. После переноса её можно удалить.

## Тематические теги

В интерфейсе используется единый закрытый справочник из 18 тегов в четырёх категориях: «Архитектурные преобразования», «Уличная сеть и мобильность», «Общественные пространства и ландшафт», «Городские сценарии». При добавлении и редактировании точки теги выбираются из раскрывающегося списка, новые произвольные строки не допускаются.

Теги характеризуют проверяемые особенности Future, а не обычные исходные объекты («панелька», «центральная улица» и т. п.). Старые записи поддерживаются функцией `normalizeTags()`: точные значения и однозначные синонимы сопоставляются с утверждёнными, остальные не превращаются в новые утверждения автоматически. «Возвращение доступа к воде» и «Природный берег вместо бетонного» объединены в «Новую доступность воды».

19.11.2026 поле `tags` на листе «Точки» приведено к утверждённым значениям. Исходные значения сохранены в отдельном листе «Архив тегов 19.11.2026» (ID точки, город, старые/новые/неперенесённые теги), чтобы каждую правку можно было проверить и при необходимости восстановить. Остальные поля точек не изменялись.

## Правило отбора тегов (19.11.2026)

Теги нужны для поиска действительно отличительных проектов и решений. Обязательные стандарты качественного преобразования не являются тематическими тегами. Из справочника сознательно исключены «Переосмысление типовой застройки», «Реконструкция без сноса», «Сокращение этажности» как слишком типичные принципы: в соответствующих ситуациях эти подходы применяются без особой маркировки.

При оценке существующей застройки следует отделять ценность исходного здания от поздней дешёвой облицовки, вывесок и иных наслоений. Их снятие может раскрыть сохранившуюся архитектуру и не требует сноса. Это правило оценки, а не повод автоматически вводить новый тег.

На листе «Чистка базовых тегов 19.11.2026» сохранены теги всех 48 точек до удаления трёх общих тем и их новый состав. После очистки в каталоге 30 назначений на 21 точке; остальные точки остаются без тегов, но не удалены. Перенос не затрагивает фотографии, промпты и остальные данные.
