# Now&Future

Личный атлас улиц «как есть» и «как могло бы быть». Сайт на GitHub Pages, данные в Google Таблице, фото в папке «Now&Future — фото» на Google Диске.

Файл `Code.gs` (отдельно от этого архива) вставляется в Apps Script таблицы, в репозиторий его класть не нужно.

Папка `seed` нужна только для переноса двух примеров. После переноса её можно удалить.

## Тематические теги

В интерфейсе используется единый закрытый справочник из 21 тега в четырёх категориях: «Архитектурные преобразования», «Уличная сеть и мобильность», «Общественные пространства и ландшафт», «Городские сценарии». При добавлении и редактировании точки теги выбираются из раскрывающегося списка, новые произвольные строки не допускаются.

Теги характеризуют проверяемые особенности Future, а не обычные исходные объекты («панелька», «центральная улица» и т. п.). Старые записи поддерживаются функцией `normalizeTags()`: точные значения и однозначные синонимы сопоставляются с утверждёнными, остальные не превращаются в новые утверждения автоматически. «Возвращение доступа к воде» и «Природный берег вместо бетонного» объединены в «Новую доступность воды».

19.11.2026 поле `tags` на листе «Точки» приведено к утверждённым значениям. Исходные значения сохранены в отдельном листе «Архив тегов 19.11.2026» (ID точки, город, старые/новые/неперенесённые теги), чтобы каждую правку можно было проверить и при необходимости восстановить. Остальные поля точек не изменялись.
