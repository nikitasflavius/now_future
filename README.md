# Now&Future

Личный атлас улиц «как есть» и «как могло бы быть». Сайт на GitHub Pages, данные в Google Таблице, фото в папке «Now&Future — фото» на Google Диске.

Файл `Code.gs` (отдельно от этого архива) вставляется в Apps Script таблицы, в репозиторий его класть не нужно.

Папка `seed` нужна только для переноса двух примеров. После переноса её можно удалить.
